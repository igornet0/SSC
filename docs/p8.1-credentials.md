# P8.1 — Ephemeral credentials & production gate

## Credential flow (after P8.1)

```
Keychain (ssc-profile-{id})
        │
        ▼
   profile_uri()  [memory only]
        │
        ▼
write_singbox_config_with_policy()
        │
        ├── runtime/singbox-ephemeral.json   (0600, while connected)
        ├── singbox-run.meta.json            (redacted ********)
        └── scrub legacy singbox-run.json
        │
        ▼
sing-box -c ephemeral.json
        │
disconnect / reset-network
        │
        ▼
cleanup_ephemeral_config()  — wipe + delete
```

## Guarantees

| Store | Credentials? |
|-------|----------------|
| `profiles.json` | No (metadata + keychain ref) |
| `singbox-run.json` | **Must not exist** with raw secrets |
| `singbox-run.meta.json` | Redacted only |
| `runtime/singbox-ephemeral.json` | Yes, only while connected |
| Web UI / API / diagnostics | Never |

## Regression

`ephemeral_config_keeps_secrets_out_of_persistent_path` in `ssc-core`.

## Live E2E

```bash
./target/release/ssc add 'vless://…'   # real URI only
./scripts/p8-e2e.sh
```

Without a live profile the harness exits with `LIVE_PROFILE_REQUIRED`.
